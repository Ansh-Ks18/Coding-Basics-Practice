# 💻 Coding Basics Practice

A structured collection of **C++ programming problems, OOP practice, and problem-solving exercises** created to strengthen coding fundamentals and build a strong foundation for DSA.

This repository documents my coding journey from **basic programming concepts to structured problem-solving practice**.

## 🎯 Purpose

The goal of this repository is to:

- Strengthen programming fundamentals
- Improve logical thinking and problem-solving
- Practice C++ consistently
- Build a strong foundation before advanced DSA
- Track progress through different practice sessions
- Develop better coding habits

## 📚 Repository Contents

### 1. C++ Practice — Session 1

Basic C++ programming practice covering fundamental concepts and beginner-level problems.

**Topics include:**
- Variables
- Data types
- Input/Output
- Operators
- Conditional statements
- Loops
- Basic problem solving

### 2. C++ Programs Practice — Session 2

A collection of additional C++ programs designed to improve programming logic and problem-solving ability.

### 3. OOP Practice Series in C++

Practice programs focused on **Object-Oriented Programming concepts**.

**Topics include:**

- Classes and Objects
- Constructors
- Encapsulation
- Inheritance
- Polymorphism
- Abstraction
- Other OOP concepts

### 4. Programming Street — 150

A collection of **150 programming/problem-solving questions** for systematic practice.

These problems are intended to improve:

- Logical thinking
- Problem-solving skills
- Coding speed
- Pattern recognition
- Programming fundamentals

### 5. PS-150

Reference document containing the Programming Street 150 problem set.
